## 一、单张图片

把图片放到 `source/images/` 目录，然后在文章里写：

```markdown
![](/images/sample-1.svg)
```

效果：

![](/images/sample-1.svg)

## 二、多张图片（画廊）

用主题自带的画廊标签，图片会自动排成网格、支持点击放大：

```markdown
{% gallery %}
![](/images/sample-1.svg)
![](/images/sample-2.svg)
![](/images/sample-3.svg)
{% endgallery %}
```

效果：

{% gallery %}
![](/images/sample-1.svg)
![](/images/sample-2.svg)
![](/images/sample-3.svg)
{% endgallery %}

## 三、本地视频

把 mp4 放到 `source/videos/` 目录，用 HTML 标签嵌入：

```html
<video src="/videos/你的视频.mp4" controls style="width:100%"></video>
```

效果（下面示例用的是在线视频文件，换成你自己的路径即可）：

<video src="https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4" controls style="width:100%"></video>

## 四、嵌入在线视频

**B站**：视频页点「分享 → 嵌入代码」，把 iframe 粘进来即可：

```html
<iframe src="//player.bilibili.com/player.html?bvid=BVxxxx&page=1" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" style="width:100%;height:400px"></iframe>
```

**YouTube**：视频页点「分享 → 嵌入」，复制 iframe 代码：

<iframe width="100%" height="400" src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

## 五、注意事项

- 图片 / 视频文件会随着 `git push` 一起上传，文件别太大（单张图片建议 500KB 以内）
- 路径以 `/` 开头表示网站根目录：`/images/xxx.png`、`/videos/xxx.mp4`
- 文件名尽量用英文和数字，避免中文和空格，否则链接里会出现乱码
- 支持 jpg / png / gif / webp / svg 等常见格式
